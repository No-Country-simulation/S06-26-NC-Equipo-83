# BE-06 Implementar lógica de gap porcentual y match de vacantes

## Descripción
Desarrollar la lógica de negocio que calcula el gap entre el perfil del usuario y los requisitos de las vacantes disponibles, mostrando el porcentaje de compatibilidad y qué habilidades faltan.

## Funcionalidades
- Algoritmo de匹配 (matching) entre perfil y vacantes
- Cálculo de gap porcentual
- Identificación de habilidades faltantes
- Recomendación de cursos/trayectorias para cerrar el gap
- Si el usuario es contratado vía plataforma, la app recibe un porcentaje

## Criterios de aceptación
- [ ] Algoritmo de matching funcional
- [ ] Gap porcentual calculado correctamente
- [ ] Items de gap identificados y devueltos
- [ ] Recomendaciones para cerrar el gap
- [ ] Tests de la lógica de matching
