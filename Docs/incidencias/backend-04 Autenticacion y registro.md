# BE-04 Implementar autenticación y registro de usuarios

## Descripción
Crear el sistema de autenticación con registro de usuarios, login, JWT y protección de rutas.

## Funcionalidades
- Registro de nuevo usuario
- Login con email y contraseña
- JWT token para sesiones
- Middleware de autenticación para rutas protegidas
- Logout y refresh token

## Criterios de aceptación
- [ ] Registro de usuario funcional con validaciones
- [ ] Login con generación de JWT
- [ ] Middleware de autenticación operativo
- [ ] Protección de rutas sensibles
- [ ] Tests de autenticación

Alta
