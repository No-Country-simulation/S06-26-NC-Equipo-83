# BE-05 Implementar gestión de perfiles personales y profesionales

## Descripción
Crear endpoints CRUD para la gestión del perfil personal y profesional del usuario, con los campos definidos en el onboarding.

## Datos personales
- Nombre, e-mail, fecha de nacimiento, género
- Escolaridad, continente, país, estado (BR), ciudad
- WhatsApp

## Datos profesionales
- Nivel (Junior, Mid, Senior)
- Área de tecnología
- Objetivo: estudiar / definir camino / buscar empleo / cambiar de empleo

## Criterios de aceptación
- [ ] Endpoint POST para crear perfil completo
- [ ] Endpoint GET para obtener perfil del usuario
- [ ] Endpoint PUT para actualizar perfil
- [ ] Validaciones de campos obligatorios
- [ ] Tests de CRUD de perfiles
