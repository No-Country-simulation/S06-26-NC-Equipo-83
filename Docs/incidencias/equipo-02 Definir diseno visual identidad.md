# TC-02 Definir diseño visual e identidad de la app

## Descripción
Definir la identidad visual de App BiT: paleta de colores, tipografía, logo, y componentes de UI reutilizables.

## Tareas
- Definir paleta de colores principal
- Seleccionar tipografía
- Crear o seleccionar logo
- Definir componentes base (botones, inputs, cards, modales)
- Crear guía de estilos rápida

## Criterios de aceptación
- [ ] Paleta de colores definida
- [ ] Tipografía seleccionada
- [ ] Logo definido
- [ ] Componentes base diseñados
- [ ] Guía de estilos documentada
