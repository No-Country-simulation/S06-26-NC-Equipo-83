# FE-05 Crear sección de mentorías

## Descripción
Crear la pantalla de mentorías donde el usuario puede ver mentores disponibles y agendar una conversación o práctica.

## Funcionalidades
- Lista de mentores disponibles con foto, nombre, área
- Botón "Solicitar mentoría"
- Modal para agenda de práctica
- Historial de mentorías agendadas
- Mensaje inspirador: "¿Quieres venir a una práctica conmigo?"

## Criterios de aceptación
- [ ] Lista de mentores visible
- [ ] Solicitud de mentoría funcional
- [ ] Agenda de práctica
- [ ] Historial de mentorías del usuario
- [ ] Diseño responsivo
