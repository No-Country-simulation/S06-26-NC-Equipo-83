# TC-01 Configurar contrato de integración entre frontend y backend

## Descripción
Definir y documentar el contrato de integración entre los miembros del equipo, especificando los formatos de request/response, códigos de error, y convenciones.

## Contenido
- Formato de endpoints (POST /orientar, POST /salud)
- Formato de request/response para cada endpoint
- Códigos de error HTTP estándar
- Formato de autenticación (JWT Bearer token)
- Nomenclatura de campos (snake_case)
- Versionado de API

## Criterios de aceptación
- [ ] Contrato de integración documentado
- [ ] Ejemplos de request/response para cada endpoint
- [ ] Códigos de error definidos
- [ ] Formato de autenticación definido
- [ ] Compartido con todo el equipo

## Prioridad
Alta
