# FE-01 Crear pantalla de onboarding (registro + perfil)

## Descripción
Crear la pantalla de onboarding completa donde el usuario se registra y completa su perfil personal y profesional.

## Funcionalidades
- Formulario de registro (nombre, e-mail, contraseña)
- Formulario de datos personales (fecha de nacimiento, género, escolaridad, ubicación, WhatsApp)
- Formulario de datos profesionales (nivel, área, objetivo)
- Validación de campos obligatorios
- Feedback visual de progreso

## Criterios de aceptación
- [ ] Pantalla de registro funcional
- [ ] Formulario de datos personales
- [ ] Formulario de datos profesionales
- [ ] Validaciones en todos los campos
- [ ] Diseño responsivo
- [ ] Integración con endpoint de registro (BE-04)
