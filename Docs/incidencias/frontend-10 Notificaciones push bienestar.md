# FE-10 Implementar notificaciones push diarias de bienestar

## Descripción
Configurar notificaciones push para recordar al usuario hacer su check-in emocional diario y enviar mensajes de bienestar.

## Funcionalidades
- Solicitar permiso de notificaciones
- Notificación diaria para check-in emocional
- Mensajes de bienestar personalizados
- Configuración de horario de notificaciones
- Opción de desactivar notificaciones

## Criterios de aceptación
- [ ] Permiso de notificaciones solicitado
- [ ] Notificación push diaria funcional
- [ ] Mensajes de bienestar rotativos
- [ ] Configuración de horario
- [ ] Opción de desactivar notificaciones

## Prioridad
Baja
