# FE-02 Crear home / dashboard principal

## Descripción
Crear la pantalla principal del dashboard donde el usuario ve un resumen de su perfil, gap actual, vacantes compatibles, y acceso rápido a los servicios.

## Secciones del dashboard
- Resumen del perfil del usuario
- Gap porcentual actual
- Próximos pasos recomendados
- Acceso rápido a: Orientación, Salud Mental, Mentorías, Eventos
- Check-in emocional del día

## Criterios de aceptación
- [ ] Dashboard con resumen del perfil
- [ ] Visualización del gap porcentual
- [ ] Cards de acceso rápido a servicios
- [ ] Check-in emocional visible
- [ ] Diseño responsivo
