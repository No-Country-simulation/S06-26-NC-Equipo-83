# FE-04 Crear visualización de vacantes con gap porcentual

## Descripción
Crear la pantalla que muestra las vacantes compatibles con el perfil del usuario, incluyendo el gap porcentual y las habilidades faltantes.

## Funcionalidades
- Lista de vacantes compatibles
- Indicador visual del gap porcentual (barra de progreso)
- Desglose de habilidades que cumplen vs. faltan
- Botón para ver detalle de la vacante
- Recomendación de cursos para cerrar el gap

## Criterios de aceptación
- [ ] Lista de vacantes desde endpoint /orientar
- [ ] Barra de progreso del gap porcentual
- [ ] Desglose visual de habilidades
- [ ] Cards de recomendaciones para cerrar gap
- [ ] Diseño responsivo
