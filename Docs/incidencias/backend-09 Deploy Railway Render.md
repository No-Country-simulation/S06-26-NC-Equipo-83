# BE-09 Configurar deploy en Railway / Render

## Descripción
Configurar el despliegue del backend en Railway o Render para el MVP, incluyendo variables de entorno, base de datos en producción y CI/CD.

## Tareas
- Configurar archivo de deploy (railway.json / render.yaml)
- Configurar variables de entorno en producción
- Conectar base de datos en producción
- Configurar CI/CD con GitHub Actions
- Probar endpoint en producción

## Criterios de aceptación
- [ ] Backend desplegado en Railway o Render
- [ ] Variables de entorno configuradas
- [ ] Base de datos en producción operativa
- [ ] CI/CD funcional (deploy automático al hacer merge a main)
- [ ] Endpoints accesibles desde producción
