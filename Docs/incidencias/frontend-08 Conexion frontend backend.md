# FE-08 Conectar frontend con endpoints del backend

## Descripción
Integrar todas las pantallas del frontend con los endpoints reales del backend, manejando estados de carga, error y vacío.

## Tareas
- Configurar cliente HTTP (fetch / axios)
- Conectar onboarding con endpoints de registro y perfil
- Conectar dashboard con endpoint /orientar
- Conectar check-in emocional con endpoint /salud
- Manejo de loading states
- Manejo de errores con feedback al usuario
- Manejo de tokens JWT en peticiones

## Criterios de aceptación
- [ ] Cliente HTTP configurado
- [ ] Onboarding conectado a backend
- [ ] Dashboard mostrando datos reales
- [ ] Check-in emocional funcional con backend
- [ ] Loading states en todas las pantallas
- [ ] Manejo de errores con mensajes amigables

## Prioridad
Alta
